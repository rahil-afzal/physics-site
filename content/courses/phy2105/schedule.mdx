## Notes on the schedule

- Each class is 80 minutes. Examinations and class tests are not counted among the 24 classes.
- A class links to the topic page, or the part of a topic page, that it covers. Several classes can share one page, so there are fewer topic pages than classes.
- Classes 21–24 (Waves and Interference) are provisional, pending confirmation from the department.
- The midterm is planned after Class 12. What it covers has not yet been confirmed.
